# Корпоративный ИИ-агент

- Использовать TypeScript в strict-режиме; не использовать `any` в публичных контрактах.
- Не читать секреты, не выполнять `push` и не изменять файлы вне workspace.
- Перед добавлением новой возможности сохранять разделение между CLI, core, provider и policy.
- Не подключать внешние endpoint или телеметрию по умолчанию.
